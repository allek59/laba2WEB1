# Лесной архив — практическая работа № 2

**Тема:** интерактивная панель управления разработкой дипломной игры об ученице Бабы-яги.

## Что сохранено из оригинала
- Все **13 изображений** из локальной базы и их исходные названия, категории, теги и описания.
- Все исходные задачи (5), заметка с концепцией игры (1), сцены тизера (5).
- Библиотека с фильтрами, поиском и скачиванием, разделы «Задачи», «Заметки и лор», «Календарь», «Мастерская тизера», главная страница и лесной стиль.
- Раздел «Для руководителя», комментарии и серверные функции убраны по запросу.

## Требования практической работы
- **Классы и ES-модули:** `UIComponent`, `Dashboard`, `ToDoWidget`, `ApiWidget`, `BooksWidget`, `NatureWidget`.
- **Управление виджетами:** добавление, сворачивание и удаление. Повтор одного типа не создаётся.
- **Задачи:** создание, отметка выполнения и удаление; расширенное редактирование в разделе задач.
- **Два разных API:** Open Library (`https://openlibrary.org/search.json`) — книги по Бабе-яге и фольклору; iNaturalist (`https://api.inaturalist.org/v1/taxa/autocomplete`) — виды грибов как референсы для сказочного леса. API не требуют секретных ключей. Для каждого есть состояния загрузки, ошибки и кнопка «Повторить».
- **Сохранение:** `localStorage` для набора и свёрнутости карточек, задач, заметок, сцен и метаданных материалов. Ошибки хранения не останавливают приложение. API-данные при загрузке запрашиваются заново.
- **Адаптивность:** две колонки виджетов на широком экране, одна на узком.

## Запуск

Проект использует ES-модули, поэтому **не открывайте `index.html` напрямую через `file://`**. Сервер Python здесь нужен только для раздачи статических файлов, а не для базы или API.

1. Распакуйте архив.
2. В папке проекта выполните `python -m http.server 8000` (или запустите через VS Code Live Server).
3. Откройте `http://localhost:8000`.

Для публикации можно загрузить папку в GitHub Pages. При публикации изображения останутся в папке `images`.

## Проверка
1. Убедитесь, что библиотека показывает все 13 исходных изображений.
2. Добавьте, сверните, удалите и верните любой виджет; обновите страницу.
3. Добавьте задачу, отметьте выполненной, удалите, перезагрузите страницу.
4. Проверьте обе API-карточки онлайн. Отключите сеть, нажмите «Повторить» — должна появиться ошибка и возможность повторить запрос.
5. Пять раз удалите и добавьте один виджет; проверьте, что обработчики не дублируются.
6. Откройте сайт на телефоне или в мобильном режиме DevTools.

**Ограничение статической версии:** новые изображения, загружаемые через браузер, ограничены 1 МБ и хранятся в `localStorage`; для больших новых файлов лучше добавить их в папку `images` и в `data.js`. Исходные 13 файлов хранятся непосредственно в архиве и не имеют этого ограничения. Изменения в браузере локальны для текущего устройства и не синхронизируются между компьютерами. JSON-экспорт сохраняет записи и метаданные.

## Использование нейросети

Примеры полезных запросов:
1. «Сохрани существующие разделы и изображения, но добавь панель независимых виджетов на классах и ES-модулях без React».
2. «Замени погоду и валюты двумя тематическими API: Open Library и iNaturalist, с загрузкой, ошибкой, повтором и отменой fetch при удалении».
3. «Добавь localStorage для задач, карточек, заметок и сцен; обработай повреждённый JSON и ошибки записи».
